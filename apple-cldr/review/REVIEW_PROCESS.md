# Review Process

## Roles

### Contributor
Proposes wording or locale data.

### Language Reviewer
A native/fluent speaker who checks naturalness, accuracy, spelling, and regional appropriateness.

### Maintainer
Merges approved data and records final decisions.

## Suggested status values

- `draft` — proposed but not reviewed
- `reviewed` — checked by at least one reviewer
- `approved` — accepted as the project default
- `disputed` — multiple valid forms or unresolved disagreement

## Decision process

1. A contributor proposes a value.
2. A reviewer checks it in context.
3. If there is disagreement, record alternatives and reasons.
4. The project chooses one default UI form while preserving accepted alternatives in notes.
5. Add reviewer/date information before marking data approved.

Do not resolve genuine language disagreement by majority vote alone; document region, generation,
community usage, and published evidence when relevant.
