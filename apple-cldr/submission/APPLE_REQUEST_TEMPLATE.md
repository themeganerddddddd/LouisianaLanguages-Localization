# Enhancement Request: Add Kouri-Vini (`lou`) and Louisiana French (`frc`) as iOS System Languages

## Request

We request that Apple consider adding Kouri-Vini (Louisiana Creole, `lou`) and Louisiana French
(Cajun French, `frc`) as selectable system languages in iOS and related Apple platforms.

## What this project provides

- reviewed native-speaker translations of common iOS interface terminology;
- a visual iOS localization preview showing translated system screens in context;
- machine-readable locale data for `lou` and `frc`;
- documented orthography and terminology conventions;
- reviewer attribution and a transparent review process;
- locale information covering dates, numbers, currency, punctuation, and other system conventions;
- links to relevant language standards and community resources.

## Language identifiers

- `lou` — Louisiana Creole / Kouri-Vini
- `frc` — Cajun French / Louisiana French

## Requested Apple action

Please evaluate these languages for:
1. inclusion in iOS system language selection;
2. broader Apple platform localization support;
3. locale support across Foundation/Locale where applicable;
4. App Store / developer localization support where applicable.
